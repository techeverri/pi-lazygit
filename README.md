# pi-lazygit

Open [lazygit](https://github.com/jesseduffield/lazygit) without leaving your current [Pi](https://pi.dev) session.

## Install

Install lazygit, then install from npm:

```sh
pi install npm:pi-lazygit
```

Or install directly from GitHub:

```sh
pi install git:github.com/techeverri/pi-lazygit
```

Run `/lazygit` in Pi. Pi returns when lazygit exits.
